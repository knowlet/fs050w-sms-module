# FS050W V2.1.0 簡訊修復套件

已有可用簡訊服務的設備，直接使用網頁收件匣。以下套件供需要修復底層服務、且已具備原廠或設備持有人預先配置的維護環境者使用。

## 已驗證的故障與適用範圍

| 現象 | 在研究設備的發現 | 本套件提供 |
|---|---|---|
| count/list 回 109 | 簡訊服務未監聽。補回服務後，可同時查 SIM 和設備儲存區。 | 啟動和停止這一版簡訊服務 |
| 送出回 610 | 追蹤顯示數據機 RAW_SEND 回 0x0038。當時只連數據網域，LTE 沒有可用簡訊網域。 | 檢查網域、暫時試用 CS+PS、確認收發後設成永久，以及回復原值 |
| 重啟後儲存區改變 | 入站簡訊實際從 SIM 讀出，先前收到的另存於設備。 | 兩個儲存區均可查閱 |

上述實機結果來自一台 FS050W V2.1.0 配中華電信 SIM。使用者確認外部手機收到簡訊，反向收件也逐字核對。原研究設備已做軟體重啟，電池與外電全部移除後的表現尚待驗證。其他電信商需以各自的收發結果判斷。

公開版服務接受台灣行動門號的本地格式或國碼 886，本文長度為 1–40 個英文字母、數字或空格。研究機目前也已更新至這個通用版。公開版已做主機模擬測試與 ARM 編譯；新打包的啟停腳本尚待在有維護環境的第二台機器實測。

新版模組在 count/list 回應中透過 `delete_one=1` 表示支援刪除單封簡訊。相容介面會傳送管理端點 `sms_del_sms_info`，並明確指定儲存區（0 為 SIM、1 為設備）和整數索引。服務固定使用有效索引與 3GPP 模式，成功時回覆同一組儲存區與索引。研究機已部署新版並通過軟體重啟驗證；尚未刪除其中的有效簡訊。刪除封包、參數拒絕及成功和失敗回應已由模擬數據機驗證。

## 使用隨附套件

1. 在電腦解壓縮 `repair-kit.zip`。在 `repair-kit` 目錄執行 `shasum -a 256 -c SHA256SUMS` 或 `sha256sum -c SHA256SUMS` 檢查完整性。請使用可信來源提供的壓縮檔。
2. 透過設備**既有的維護管道**把整個 `repair-kit` 放入本機可執行、由維護者管理的目錄。保留 `bin/` 下六個檔案的執行權限。在同目錄的維護終端執行下面的命令。一般網頁管理密碼只足以登入簡訊介面。尚未取得原廠提供的套件安裝入口或簽章更新包，原廠出廠機只有網頁帳密時需請維護單位協助部署。
3. `sh apply.sh check` 會比對 V2.1.0 韌體函式庫、行動數據、SIM、實體按鍵及 APN，然後讀取目前的數據機狀態。請先保存輸出和原有 APN 編號。啟動模組前應能在原廠網頁管理設備。
4. 若簡訊清單回 109 且顯示 `SMS socket absent`，執行 **`sh apply.sh start`**，接著回網頁重新整理收件匣。已使用該位置的服務會保留。停用這份套件啟動的服務，執行 `sh apply.sh stop`。停止時需使用原來那份套件及目錄。

啟動效果維持到停止服務或重啟設備。設備若提供受支援的服務管理器，可由維護單位整合 SMS 行程。本套件未驗證出廠版提供這類公開介面。NAS 永久設定和 SMS 行程開機自啟是兩件事。

## 只在讀值符合時修復數據機網域

`610` 也可能由收件路由檢查失敗引起。只有診斷同時顯示 `service_domain_preference value=1`、`cs_attach=2`、`ps_attach=1`、`lte_sms_domain value=0` 且數據連線正常時，才適用以下對照。網域切換可能讓行動網路短暫重新註冊，請在設備旁操作。

| 維護終端命令 | 作用 |
|---|---|
| `sh apply.sh trial` | 保留這次開機的原始讀值，要求數據機暫時使用 CS+PS。 |
| `sh apply.sh check` | 重新註冊後應看到網域偏好 2、CS/PS 都為 1、LTE SMS 網域 3。用網頁寄一封給自己控制的另一支手機，再回寄一封，逐字核對收件內容。 |
| `sh apply.sh restore-trial` | 若試驗無效或數據異常，將這次試驗回復到 PS only。 |
| `sh apply.sh commit` | 雙向收發成功後，在同次開機保存永久偏好。腳本比對 APN、選網、頻段、行動數據和簡訊網域。之後可由管理頁正常重啟再驗證。 |
| `sh apply.sh restore-original` | **僅限已記錄這台設備原本為 PS only**，用於永久回復。這項命令可在重啟後使用。回復後要再次查讀值和行動數據。 |

若目前已經是 CS+PS 且 LTE SMS 網域可用，直接測試收發即可。若 QMI 無法連線，請先恢復設備本機維護連線。斷電未驗證為可靠的回復方式，永久設定需要明確寫回。本套件會使用原廠簡訊路由檢查；發送後，數據機可能把後續入站訊息存到設備儲存區。

## 從原始碼重建

解壓後已附可直接使用的 ARM 程式。維護者如需重建，請備妥自己取得的 FS050W V2.1.0 解包 `system` 目錄、Python 3、主機 C 編譯器、支援 ARM 的 LLVM clang 和 ld.lld。從包含本腳本的目錄執行以下一行。路徑可含空白。

```sh
sh prepare-repair.sh "/path/to/FS050W-V2.1.0/system" ./my-repair-kit.zip
```

腳本先核對韌體檔案的 SHA-256，再測試門號編碼、收件儲存區和 NAS 訊息內容。輸出的 ZIP 包含服務、唯讀診斷、暫時設定與回復、永久設定與回復、原始碼和雜湊清單。腳本所有操作都在電腦本機執行。可用環境變數 `CLANG`、`LLD`、`CC` 指定編譯器。公開包只收錄自行建置的程式，連結時使用的原廠函式庫由設備本身提供。
